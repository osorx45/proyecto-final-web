COMO INICIAR EL SISTEMA BIC (en tu computadora)
================================================

Antes de empezar: abre Docker Desktop y espera a que diga que esta corriendo.


TERMINAL 1 - Base de datos (MongoDB)
------------------------------------
cd "C:\trabajos 1lap\app web\proyecto final\app final"
docker compose -f docker-compose.dev.yml up -d
docker ps

  -> Espera a que bic-mongodb diga "(healthy)" (unos 15 segundos).
  -> Esta terminal ya la puedes cerrar; Mongo sigue corriendo en Docker.


TERMINAL 2 - Backend (API)
--------------------------
cd "C:\trabajos 1lap\app web\proyecto final\app final\Backend"
npm run dev

  -> Debe decir: "Servidor BIC activo en puerto 3000."
  -> No cierres esta terminal.


TERMINAL 3 - Frontend (pantallas)
---------------------------------
cd "C:\trabajos 1lap\app web\proyecto final\app final\Frontend"
npm run dev

  -> No cierres esta terminal.
  -> Abre en el navegador: http://localhost:5173
  -> Entra con numero de empleado 1 y la contrasena de ADMIN_PASSWORD
     (esta en Backend\.env).


PARA APAGAR TODO
----------------
- En las terminales 2 y 3: Ctrl + C
- La base de datos:
    cd "C:\trabajos 1lap\app web\proyecto final\app final"
    docker compose -f docker-compose.dev.yml stop
  (Los datos se conservan. NO uses "down -v": eso borra la base de datos.)


PRUEBA DE PRODUCCION EN TU COMPUTADORA (como quedara en AWS)
-----------------------------------------------------------
Levanta 4 contenedores: proxy (Nginx), frontend, backend y MongoDB.
Usa la misma base de datos que el modo de desarrollo.

1) Si tienes corriendo "npm run dev" en las terminales 2 y 3, detenlos (Ctrl + C).

2) En una terminal:
cd "C:\trabajos 1lap\app web\proyecto final\app final"
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build

  -> La primera vez tarda varios minutos (descarga imagenes y compila React).
  -> Revisa que todo este arriba:
     docker compose -f docker-compose.yml -f docker-compose.local.yml ps
     Deben aparecer bic-proxy, bic-frontend, bic-backend y bic-mongodb.

3) Abre en el navegador:
   http://bic.localhost                     (la aplicacion)
   http://api.bic.localhost/api/health      (debe responder "correcto")

Si algo falla, mira los mensajes del contenedor:
   docker compose -f docker-compose.yml -f docker-compose.local.yml logs backend
   (o proxy, o frontend)

Despues de cambiar codigo, repite el comando del paso 2 (el --build reconstruye).

Para apagarla:
   docker compose -f docker-compose.yml -f docker-compose.local.yml stop
